HTTP JSON／SSE LLM・ASR・TTS 性能診断ベンチマーク仕様

local-nodeの遅延をOpenAI互換HTTP非streaming JSON、HTTP SSE、ASR、TTSへ分解し、 LLMと音声2系統を同時利用した場合の干渉を再現可能な形で比較する。 実装はdeploy/local-node/scripts/performance-larm.tsであり、公開HTTP APIだけを測定する。

report schema
larm-performance-diagnostic version 3
既定反復
warmup 1回、測定5回
既定系列
llm、llm-sse、asr、tts、 mixed、mixed-sse

測定契約

workloadごとの固定入力と主要指標
workload 入力 主要指標
LLM JSON 1から40までを出力する固定prompt、既定max_tokens=64 first byte、total、completion tokens、output tokens/sec
LLM SSE JSONと同じprompt・token上限、stream=true first byte、最初のcontent delta、total、delta数、output tokens/sec
ASR 固定音声、または測定前にTTSで一度だけ生成するmemory上の音声 first byte、total、RTF、audio seconds/sec
TTS 日本語の固定文、VOICEVOX通常音声、WAV first byte、first playable audio、total、RTF、audio seconds/sec

LLMのtoken数はusage.completion_tokensを優先し、usageがない場合だけcontent event数を代替値として明記する。SSEはUTF-8、event JSON、meaningful delta、finish reason、 [DONE]を増分検証する。response本文、音声、credentialはreportへ保存しない。

同時利用scenario

mixedはLLM JSON、ASR、TTSを、mixed-sseはLLM SSE、ASR、TTSを 一つのAllocationへ束ね、同じevent loop turnで各1要求を開始する。reportにはlaunch skewと、 単体比のp95 total latencyおよびp50 processing speedの劣化率を残す。

LARM_PERF_ASR_URLを指定した場合、credentialを含まないloopbackのOpenAI互換ASRを production Bindingの代わりに使う。mixedではLLMとTTSだけを通常Allocationへ固定し、外部ASRと 同時に開始する。

観測と失敗条件

  • 最小system／accelerator memory available bytes
  • 最大active execution、最大queue depth、HTTP 429増分
  • route、runtime、release、fallbackの実identity
  • daemon boot epoch、config revision、release commitの開始前後一致

推論error、telemetry error、identity変化のいずれかがあればpassed=falseかつ非zeroで 終了する。性能値そのものは診断reportであり、release昇格のSLO閾値は別canaryで校正する。

実行方法

set -a
source /etc/larm/larm.env
set +a
bun run perf:diagnostic

LARM_PERF_SCENARIOSは llm,llm-sse,asr,tts,mixed,mixed-sseの部分集合、反復は LARM_PERF_ITERATIONS、warmupはLARM_PERF_WARMUPSで指定する。 固定音声はLARM_PERF_AUDIO_FILE、no-overwriteのrepository外証跡は LARM_PERF_OUTPUTへ絶対pathで指定する。

実装受入

  • JSONとSSEが同じ公開model、route、runtime、releaseを使用する。
  • SSEの最初のmeaningful deltaを全文完了前に観測できる。
  • 全6 scenarioでfallback 0、error 0、identity不変を検証できる。
  • 専用transport、Agent claim、native companionへ依存しない。
