ローカルAI基本セットとオンデマンドRuntime Variant

利用者から見えるAgent Profileと基本的な会話能力を変えず、音楽生成、画像生成、OCR、CVなどの accelerator workloadだけを必要時に追加する。内部実装ではこれをprofile切替ではなく、同一profileへ capabilityを一時追加するRuntime Variantとして扱う。基本応答セットとmusic/image Variantのrepository設定、on-demand systemd unit、排他起動scriptは更新済みで、隔離portを使った実モデルE2Eにも合格した。production serviceの install、restart、切替はまだ行っていない。

設計原則

  • 会話、Tool use、音声入出力、Embeddingからなる基本セットはvariant切替中も維持する。
  • Agent Profile、認証主体、会話session ID、公開model IDはvariantで変更しない。
  • Variantは追加capability、resource lease、lifecycleを束ねたoverlayであり、別profileではない。
  • 重量級Variantは同時に一つだけ起動し、固定swap groupではなく明示的なaccelerator leaseで排他する。
  • Linux、ROCm allocator、一時bufferのため、起動後も20 GB以上のlive headroomを残す。
  • Variantの失敗やOOM予兆で基本セットを停止せず、Variantだけをrollbackする。

Admissionと排他

  1. 呼出元は同じAgent Profileのまま、必要な追加capabilityを要求する。
  2. LARMは基本セット、要求Variant、20 GB安全床を含む静的予算を検査する。
  3. freshなsystem memory、accelerator memory、service activityを検査する。
  4. 競合する重量級Variantがあれば、新規jobをqueueするか既存job完了後に切り替える。
  5. 対象Runtimeをloadし、semantic readiness成功後だけjobを開始する。
  6. job完了後は短いidle TTLを適用し、期限後にVariantだけをunloadする。
  7. load、health、推論、unloadのいずれかが失敗しても基本セットへ収束させる。

music、image、ocrは同じ accelerator-media-heavy排他groupに置く。軽量cvと expressive-ttsはmemory上は併存可能でも、foreground音声SLOを満たすことをmixed benchmarkで 認定するまでは重量級Variantと同時実行しない。

Scheduling

  • ASRと短いQwen 2B decisionをforeground最優先とする。
  • Ornithの音声応答をmedia generationより優先する。
  • 画像・音楽生成は非同期jobとし、音声活動中はstep境界でyieldまたは開始を遅延する。
  • OCRは対話で結果を待つ場合があるため短文jobを優先し、長い文書は非同期化する。
  • 同一Variant内もbatch 1を既定とし、複数生成要求はqueueする。

公開契約

Variant名をroutingの正本にせず、要求capabilityから内部Variantを選ぶ。これによりmodelやruntimeを将来交換しても Agent Profileを変更せずに済む。公開状態には利用可能capability、Variantの cold、loading、ready、busy、推定ready時間を含める。 非同期jobは取消、進捗、成果物取得、失敗理由を提供し、provider固有pathをconsumerへ公開しない。

導入条件

  • Ornith 1×128Kの実測peakとMTP性能を再測定する。
  • Qwen 2B 64Kの予約値を実測し、Tool use回帰試験を行う。
  • Qwen ASRの定義を観測peak以上へ修正する。
  • 各Variant単独と、ASR・Ornith応答を含むmixed workloadでTTFC、RTF、peak memoryを測定する。
  • image Variantは総使用量108 GB未満、その他は100 GB未満を目標にする。
  • OOM、cancel、provider crash後に基本セットへ自動収束することをfault試験する。
