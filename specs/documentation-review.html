Review時の実ホスト観測

読取確認ではProvider serviceの8080から8084がlistenし、Qwen TTSを含むProvider unitはactiveでした。 一方、larm-daemon.serviceはinactiveかつ未installで、Qwen TTSはenabledでした。これはrepositoryが定義する次のdesired state、すなわちLARM常駐とQwen TTS boot disabledへ未収束の状態です。このreviewではsystemd、UFW、processを変更していません。

この節は2026-08-28の観測記録であり、現在状態の正本ではありません。運用判断の直前に systemctl is-active、systemctl is-enabled、ss -ltnpを再実行します。

レビュー時点の継続制限

  • STTとTTSの安定Gatewayはレビュー実施時点で未実装であり、resolveした個別endpointを使用していた。
  • directory modelはAPI staging対象外である。
  • Resident artifactはAPIからactivationできない。
  • active Allocationはdaemon再起動後に復元しない。
  • 35Bはproduction Registryへ登録していない。
  • VOICEVOXの0.vvm releaseはREADMEに記録されているが、file manifestとchecksumは未整備である。
  • 過去のgnosis性能値にはrepository内のraw dataがなく、再現可能なrelease gateではない。
