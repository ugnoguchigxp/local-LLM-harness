SAAA 会話モデル・Context Window 接続仕様

SAAAの会話セッションは、LARM Agent Connection APIが返すclaimを接続情報の正本とする。 SAAA実装へmodel ID、endpoint、短期credential、context windowを重複して固定しない。

モデルの役割

SAAA会話セッションで取得するProviderと責務
Provider モデル 役割 Context window
backchannel LFM 2.5 1.2B JP 相槌のack／defer判定だけを行う 65,536 token
llm Qwen 3.8 27B Q4_0 + MTP 会話本文、推論、tool call、tool結果を受けた最終回答を生成する 230,400 token（225 Ki token）
asr Qwen3 ASR 1.7B 既存の音声認識 非該当
tts VOICEVOX 既存の音声合成 非該当

接続契約

  • SAAAは明示profile saaa-qwen38を要求する。
  • claimは四Providerのmodel、protocol、Gateway URL、短期credentialを返す。
  • Chat Completions ProviderのclaimはcontextWindowを返し、SAAAは値を検証してsessionへ保持する。
  • Qwenのinput budgetは230,400からoutput reserve 4,096とsafety margin 1,976を引いた224,328 tokenとする。
  • LFMのinput budgetは65,536からoutput reserve 512とsafety margin 1,024を引いた64,000 tokenとする。
  • LFMは回答本文、tool権限、完了判定、最終回答の書き換えを所有しない。最終回答はQwen本文を既存TTSへ渡す。

旧profile saaa-qwen38-kv-memと旧Provider decision-defaultはこの接続経路では使用しない。 ContextStill用のQwen 3.5 2B decision Providerは別用途として残す。
