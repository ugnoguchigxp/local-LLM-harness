Review後の不変条件

  • Qwen 3.8 27Bを含むResident floorのmemoryは状態にかかわらず予約する。
  • AllocationのBindingは変更しない。固定Runtimeが停止した場合は別Runtimeへ暗黙移動しない。
  • 配備中のRuntimeと共有artifact ownerには新しいAllocationを入れない。
  • Allocationがrelease、expire、timeoutした後に新しいartifactをactivateしない。
  • artifact operationは破壊的処理より先にjournalへ永続化する。
  • Qwen TTSはPreferredとしてboot時COLDを許容し、Resident serviceはLARMの権限で変更できない。

受入確認

  • bun run checkでsource-only、Spec HTML、TypeScript、全testを検証する。
  • Bash scriptはbash -n、Python adapterはast.parseでsyntax確認する。
  • systemd unitはsystemd-analyze verifyで静的検証する。
  • live smokeはResident serviceを停止・再起動せず、health、Allocation、Gateway、releaseだけを行う。

継続する制限

directory modelはsnapshot単位のhash manifestがないため無人staging対象外です。Resident artifact activationも引き続きattended operationです。35Bはproduction Registryへ登録していません。
