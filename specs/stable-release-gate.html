LARM Stable Release Gate

repository gateとproduction gateを混同しないための最終判定表です。コードと隔離testの完了だけでは stableへ昇格せず、commissioningとAmbient client canaryの両方を要求します。

Rollback条件

error budget、latency、memory headroom、fallback、epoch contract、operation leakのいずれかが基準外なら、 Ambient clientをdirect Providerへ戻し、release-larm.sh rollbackでLARMだけを前世代へ戻します。 Provider processとmodel weightはLARM rollbackの対象にしません。
